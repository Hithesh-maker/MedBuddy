# MedBuddy — Intelligent Health Management System (Consolidated)

Consolidated full-stack Node.js + SQLite health portal uniting the MedBuddy static/client pages with a REST backend, salted `scrypt` authentication, appointment scheduling, medication tracking, symptom logging, payment processing, and automated tests.

*(Note: Consolidates the earlier duplicate `Web project/MedBuddy` scaffold into this unified backend + frontend server.)*

## Run Locally
```bash
npm start
# Open http://localhost:3000
```

## Run Tests
```bash
npm test
```
